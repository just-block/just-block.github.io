# Chrome Web Store listing

The title and summary come from `packages/extension/public/_locales/<lang>/messages.json` and ship with each release. The description below isn't in the build. Paste it into the developer dashboard under Store listing → Description.

## Description (en)

```
Just Block is a simple site blocker for Chrome. Block distracting websites in one click and get your time back for what truly matters.

Add YouTube, Instagram, TikTok, Reddit, news or any other website to your block list and it's blocked right away. When you open a blocked site, you see a calm page reminding you that you blocked it for a reason.

Want to unblock a website? Solve a captcha first. That small bit of friction stops impulsive unblocking: no password to forget and no friend needed to keep it for you. It's inspired by Atomic Habits: make bad habits harder.

⭐ Features

✅ Block the current website in one click, or add any site manually
✅ Blocks the whole domain, subdomains included (block chess.com and learn.chess.com is blocked too)
✅ Captcha to unblock, edit or delete a site, so you can't give in to procrastination on a whim
✅ Calm blocked page with no memes to distract you
✅ No sign up, no account, no subscription
✅ Light and dark theme, available in 11 languages

💎 Pricing

Block up to 3 websites for free. Unlimited blocking is a one-time payment of $2.99 for lifetime access, with no subscription.

🎯 Who it's for

Students who need to stay focused while studying, remote workers, developers, writers and anyone who wants to stop procrastinating, cut down on social media and build self control.

❓ How to block a website on Chrome

1. Click the Just Block icon in the toolbar
2. Click "Block current website", or "Add website manually" and enter a URL such as instagram.com
3. Confirm, and the site stays blocked until you solve a captcha

Website: https://just-block.github.io
```
